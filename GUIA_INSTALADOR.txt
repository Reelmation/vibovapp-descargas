CÓMO CREAR EL INSTALADOR DE WINDOWS (Vibovapp-Setup.exe)
===========================================================
Se hace una sola vez la preparación y después cada instalador nuevo son 3 clics.

PREPARACIÓN (una vez)
1. Crea una cuenta gratis en github.com.
2. Arriba a la derecha: "+" > "New repository". Nombre: vibovapp. Elige PRIVATE (privado, solo tú lo ves). Create repository.
3. En la página del repositorio: "uploading an existing file". Arrastra TODO el contenido de la carpeta vibovapp
   (descomprime el zip primero). No subas la carpeta "productos".
   IMPORTANTE: la carpeta oculta ".github" también debe subirse. Si Windows no la muestra, en el Explorador: Vista > Mostrar > Elementos ocultos.
   Si no se puede, crea el archivo a mano: "Add file" > "Create new file", escribe como nombre  .github/workflows/windows.yml
   y pega dentro el contenido de ese archivo.
4. Presiona "Commit changes".

CREAR EL INSTALADOR (cada vez)
1. En tu repositorio, pestaña "Actions".
2. A la izquierda "Crear instalador de Windows" > botón "Run workflow" > "Run workflow".
3. Espera unos 10 minutos (círculo amarillo = trabajando, palomita verde = listo, X roja = falló: mándame captura).
4. Entra a esa ejecución, baja hasta "Artifacts" y descarga "Vibovapp-Setup". Es un zip con Vibovapp-Setup.exe.

PRUEBA
- Instálalo en una computadora SIN Python (o pídele a alguien de confianza).
- Windows puede decir "Windows protegió tu PC": clic en "Más información" > "Ejecutar de todas formas". Es normal sin firma.
- Revisa: abre, crea producto, sube un clip y un audio, crea un video.

NOTAS LEGALES (revisar antes de vender)
- El instalador incluye ffmpeg (versión GPL, con el codificador H.264). Se usa como programa aparte; hay que conservar su archivo de licencia
  (ya se copia como LICENCIA_FFMPEG.txt) y poner en tu página de venta un enlace a https://ffmpeg.org y al código fuente de ffmpeg.
- H.264 tiene patentes; para un producto de pago conviene consultarlo con un abogado.


ACTUALIZACIONES AUTOMATICAS (una sola preparacion)
===================================================
Los programas instalados avisan "Hay una version nueva", dicen que cambio y se actualizan con un clic.
Todo el procedimiento (repositorio publico de descargas, variable DESCARGAS_REPO, como publicar cada version) esta en GUIA_ACTUALIZACIONES.txt.
